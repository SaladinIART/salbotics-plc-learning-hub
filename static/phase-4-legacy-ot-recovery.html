Phase 4: Legacy OT Recovery And Read-Only Data Bridging

obsolete PLCs, XP/7 HMIs, missing software, fragile production, safe shadow monitoring

The real plant problem

A profitable machine may still depend on an obsolete PLC and a Windows XP/7 HMI. The installer is gone, the license dongle is lost, the vendor is unavailable, and production cannot stop. Phase 4 teaches the professional response: recover evidence, isolate risk, observe read-only, build a bridge, and plan migration later.

Boundary

This module is authorized recovery training, not offensive hacking or license bypassing. The demo uses simulated registers on localhost. It does not connect to a real PLC and does not expose write, force, or reset commands for legacy equipment.
