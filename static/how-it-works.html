One repeated scan

The simulator behaves like a small PLC. Every scan reads the input table, solves the Ladder-style rules, updates timers/registers, then writes the output table. The browser is only the HMI view of that live state.

1Read inputsI0.0-I0.7
2Solve rungscontacts -> coils
3Update memoryT0-T6 / R0-R4
4Write outputsQ0.0-Q0.5

Normal running: the lights take turns

Scenario 1: Auto Cycle · normal running sequence

Press START and the lights run by themselves. Each road gets green, then yellow, then a short all-red gap before the other road starts.

Like: Taking turns at a junction, with a pause so nobody crashes.

Show technical detailsHide technical details

Technical details are in English.

What happens

  1. Student presses START.
  2. RUN_LATCH seals in so the PLC keeps running after START is released.
  3. Phase timer advances through green, yellow, all-red, then the opposite road.
  4. Output interlocks prevent NS_GREEN and EW_GREEN from being on together.

A crossing button is remembered

Scenario 2: Pedestrian Request · latched request

Pressing the crossing button is remembered, even after you let go. The PLC serves the request when that road next turns green.

Like: A lift button that stays lit until the lift arrives.

Show technical detailsHide technical details

Technical details are in English.

What happens

  1. Student toggles PED_NS or PED_EW.
  2. The request latches into an internal memory bit.
  3. The latch stays on until the matching road receives service.
  4. The request clears only after the matching green phase is reached.

Beginner rule: momentary field signals often need memory bits so the PLC does not miss them between scans.

A waiting car can extend green, up to a limit

Scenario 3: Vehicle Demand Extension · green can extend, but not forever

A car sensor can keep a green light on a little longer. There is always a maximum, so the other road never waits forever.

Like: Holding a door for someone, but not all day.

Show technical detailsHide technical details

Technical details are in English.

What happens

  1. Vehicle sensor turns on during that road's green phase.
  2. Base green still has to complete.
  3. If demand remains, green can extend until the maximum green limit.
  4. When max time is done, phase must advance.

This is demand logic plus a hard limit. Industrial control often allows flexibility, then enforces a maximum.

Emergency: everything turns red

Scenario 4: Emergency All-Red · highest priority override

The emergency switch beats every other rule. All lights turn red at once and an alarm is recorded.

Like: A fire alarm that stops every lift in a building.

Show technical detailsHide technical details

Technical details are in English.

What happens

  1. EMERGENCY input turns on.
  2. Normal phase outputs are ignored.
  3. Both green outputs and both yellow outputs turn off.
  4. Both red outputs turn on and an alarm is logged.

Night mode: the red lights blink

Scenario 5: Night Red Flash · normal sequence paused

At night the normal sequence pauses. Both red lights blink together and the greens stay off.

Like: A quiet junction flashing red after midnight.

Show technical detailsHide technical details

Technical details are in English.

What happens

  1. NIGHT_MODE selector turns on.
  2. Normal green/yellow sequence pauses.
  3. Flash timer T6 toggles NIGHT_FLASH_ON.
  4. Red lamps blink together; greens stay off.

Stepping through by hand, safely

Scenario 6: Manual Safe-Step · one safe phase at a time

A technician can step through the lights one press at a time. Even then, the PLC only allows a safe next step.

Like: Turning pages one by one, without skipping the warning page.

What happens

  1. Student presses MANUAL STEP.
  2. The controller changes only to the next allowed phase.
  3. All-red steps remain in the sequence.
  4. Green conflict interlock still protects the outputs.

Two buttons at once: a fault

Scenario 7: Fault And Reset · stuck pushbutton training fault

If START and STOP are on together, the PLC treats it as a broken button. Everything goes red until someone fixes it and presses reset.

Like: A machine that refuses to run when two opposite buttons are held.

Show technical detailsHide technical details

Technical details are in English.

What happens

  1. START and STOP are both on at the same time.
  2. PLC treats that as an impossible pushbutton state.
  3. FAULT_ACTIVE turns on and outputs go safe all-red.
  4. Student clears the bad input, then presses RESET FAULT.

Check yourself

Think of your answer, then tap the question to see it.

What happens to both roads between green phases?

Both turn red for a moment, so the junction clears.

You tap the crossing button and let go. Is the request lost?

No. The PLC remembers it (a latch) until that road turns green.

Which input beats every other rule?

The emergency switch. All lights turn red at once.
