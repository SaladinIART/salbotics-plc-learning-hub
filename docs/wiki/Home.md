# Salbotics PLC Learning Hub Wiki

Welcome to the **Salbotics PLC Learning Hub**, an open educational project by **Salbotics Solutions**.

Mission: one portable place where beginners, technicians, and recruiters can see PLC thinking, Ladder logic, HMI/SCADA concepts, industrial process examples, and local analytics without needing real hardware.

## What The Project Teaches

- Absolute-beginner introduction using everyday machines: washing machine, lift, automatic gate, escalator, rice cooker and car-park barrier.
- PLC scan cycle and Ladder-first thinking.
- Industrial HMI panels and SCADA-style reading.
- Traffic-light trainer with I/O, timers, alarms, and event log.
- Realistic industrial situations: Omron, Siemens, WECON, PAC, Raspberry Pi industrial, Arduino industrial PLC options.
- Oil-palm process learning: FFB reception, sterilizer, thresher, digester, screw press, clarifier, purifier, CPO tank, POME, boiler/utility loop, and conveyor handling.
- Communications overview: RS-232, RS-485, Ethernet, Modbus, OPC UA, MQTT, localhost, LAN IP, and local server basics.
- Phase 3 local analytics: SQLite historian, simulated oil-palm KPIs, trends, events, OT/IT/MES/ERP concepts, and management dashboard value.
- Phase 4 legacy OT recovery: obsolete PLCs, Windows XP/7 HMIs, missing software/license situations, read-only bridges, virtual registers, and simulated RS-232 lessons.

## Important Boundary

This is educational software. It is not certified industrial control software, traffic-control software, machinery-safety software, boiler protection, pressure protection, or production SCADA.

Keep the live FastAPI simulator local unless proper authentication, network controls, and review are added.
